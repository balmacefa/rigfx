rigfx — one animation, any body

A pixel-art skeleton rig whose animations are body-independent. Define a character as a few proportion multipliers in a JSON file and every existing move (sword combo, fireball, ground pound…) re-aims hands and feet to the new limbs. 17 bodies so far, styled with procedural helmets, horns, hats and capes. No re-animating, no GPU, MIT licensed. · Una animación, cualquier cuerpo: define las proporciones en un JSON y reutiliza todos los movimientos.

Add your own character

{ "name": "giant",
  "body": { "legS": 1.35, "torsoS": 1.3, "armS": 1.4, "headS": 0.9, "thick": 1.5, "widthS": 1.3 },
  "pal":  { "shell": ["#dff7c8","#a7e07c","#6cc04a","#479632"], "core": ["#4f9630","#357024","#235018","#235018"],
            "ink": "#0c1a08", "seam": "#163a12", "mark": "#d0ff90" } }

Drop it in chars2d/ and run node retarget.mjs. Full steps in the README.

Built on patch-gg/pixelfx (MIT): the effects and the 3D-to-pixels rig are theirs. The body retargeting layer and character library are MIT © balmacefa. Known limit: weapons don't scale with the body yet.
